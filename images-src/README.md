Кладіть сюди оригінальні фото (jpg, png, heic…) — у підпапки, наприклад `handmade/`, `journal/`, `story/`.

Оптимізовані копії автоматично з'являться в `public/images/` у форматі WebP
(запускається само перед `npm run dev` / `npm run build`, або вручну `npm run images`).

Оригінали в Git не потрапляють (див. .gitignore) — зберігайте їх окремо.
