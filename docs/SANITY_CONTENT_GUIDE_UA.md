# Інструкція: як керувати сайтом Galyna's World через Sanity Studio

Ця інструкція для Галини. Усе, що описано тут, робиться в браузері або в телефоні, **без коду**.
Сайт сам оновлюється через кілька хвилин після натискання кнопки «Опублікувати».

> **[Screenshot: вхід у Studio — сторінка з кнопкою входу]**

---

## 1. Як відкрити і увійти в Studio

1. Відкрийте в браузері адресу сайту та додайте до неї `/studio`.
   Приклад: `https://ваш-сайт.com/studio`
2. Увійдіть тим способом, який вам надіслали: за посиланням із листа-запрошення або через обліковий запис, з яким вас додали.
3. Після входу зліва буде меню. Воно працює і на телефоні, і на комп'ютері.

> **[Screenshot: ліве меню Studio з розділами]**

**Розділи меню:**

| Розділ у меню | Що це |
|---|---|
| 🏠 Головна сторінка | Тексти та фото головної сторінки сайту |
| Щоденник | Вірші, думки, записи з життя |
| Вироби | Вироби на продаж (з ціною та статусом) |
| Малюнки | Картини для галереї «Мої малюнки» |
| Теми (теги) | Мітки для малюнків і віршів |
| Оновлення | Записи «Що вдалося» (див. розділ 8) |
| 💰 Підтримка | Сума зібраного, мета, посилання на Monobank |
| Прозорість | Звіти та медичні документи (PDF) |

---

## 2. Як додати новий виріб

1. Зліва натисніть **Вироби**.
2. Натисніть **+ Створити** (або «Create new») у верхньому правому куті.
3. Заповніть поля (див. таблицю в розділі 9).
4. Натисніть **Опублікувати** внизу.

> **[Screenshot: Вироби → Створити новий]**

Порядок заповнення:
1. **Фото** — додайте 1–5 фото. Перше фото стане обкладинкою. Порядок змінюється перетягуванням.
2. **Назва** — спочатку українською (поле «Українською»), потім за бажанням англійською.
3. **Адреса сторінки** — натисніть **«Згенерувати»**. Адреса з'явиться сама з назви.
4. **Опис** — розповідь про виріб (абзаци розділяйте порожнім рядком).
5. **Ціна, грн** — необов'язково. Якщо ціни немає, поле залиште порожнім.
6. **Статус** — оберіть: *В наявності*, *На замовлення* або *Продано*.

---

## 3. Як змінити існуючий виріб

1. Вироби → оберіть потрібний виріб зі списку.
2. Змініть потрібні поля.
3. Натисніть **Опублікувати**.

**Коли виріб продано**, не видаляйте його. Змініть **Статус** на *Продано*. Сторінка виробу лишиться (її бачать люди, які шукають саме цей виріб), а кнопка замовлення зникне.

---

## 4. Фото: додати, замінити, видалити

**Додати:** натисніть **Add item** (або «+») у блоці «Фото» і виберіть файл із комп'ютера чи телефону.

**Замінити:** натисніть на фото → **Replace** (замінити) → виберіть новий файл.

**Видалити:** натисніть на фото → значок смітника (Delete).

**Головна частина фото (важливо для облич).** Після завантаження натисніть на фото → **Hotspot** і поставте крапку на обличчя або на виріб. Тоді на маленьких картках фото не обріжеться по обличчю.

**Опис фото (необов'язково).** Поле «Що на фото» — кілька слів про те, що видно. Це допомагає людям з вадами зору.

**Рекомендації щодо фото:**
- Формат: **JPG** або **PNG** (фото з телефона зазвичай підходять).
- Розмір (рекомендація): найдовша сторона **не менше 1200 пікселів**. Великі файли не потрібно стискати вручну.
- Не треба стискати фото вручну: сайт сам підбирає потрібний розмір.
- Для **виробів** і **малюнків** найкраще квадрат або вертикальне фото, на якому весь предмет видно повністю.
- Для **головної** (фото з сином) — горизонтальне фото, на якому обличчя не обрізані.

## 5. Українська і англійська

У багатьох полях є два віконця:
- **Українською** — обов'язкове (там, де стоїть зірочка або напис «Заповніть українською»).
- **English (необов'язково)** — переклад. Якщо його немає, англійська версія сайту покаже текст українською. Це нормально.

**Важливо:** не змінюйте українське поле, коли додаєте переклад. Англійський текст вписуйте тільки в англійське поле.

---

## 6. Щоденник: вірші, думки, історії

1. Зліва натисніть **Щоденник** → **+ Створити**.
2. Заповніть:
   - **Назва** (обов'язково, українською).
   - **Категорія** — *Вірш*, *Думки*, *Наше життя*, *Творчість* або *Новини*.
   - **Текст** (обов'язково, українською). Переноси рядків зберігаються, тож вірш виглядатиме так само, як тут.
   - **Дата** — за замовчуванням сьогодні. Її можна змінити.
   - **Адреса сторінки** — натисніть **«Згенерувати»**.
3. Необов'язково: **Фото**, **Теми (теги)**, **Короткий опис для картки** (якщо порожньо — сайт візьме перший рядок тексту).
4. Натисніть **Опублікувати**.

**Щоб змінити запис:** відкрийте його зі списку, змініть текст і натисніть **Опублікувати**.

> **[Screenshot: Щоденник → запис з полями Назва, Категорія, Текст]**

---

## 7. Малюнки

1. Зліва **Малюнки** → **+ Створити**.
2. Заповніть:
   - **Фото малюнка** (обов'язково) + Hotspot.
   - **Назва** (обов'язково, українською).
   - **Техніка** — наприклад, «Акварель».
   - **Рік**.
   - **Теми (теги)** — можна кілька.
   - **Показувати кнопку «Мене цікавить»** — увімкнено, якщо картину можна запитати. Вимкніть, якщо картина не продається.
   - **Показувати на сайті** — вимкніть, щоб картина тимчасово зникла з сайту. Так можна сховати її без видалення.
3. Натисніть **Опублікувати**.

**Теми (теги)** створюються в розділі **Теми (теги)**: назва, тип («Для малюнків» або «Для віршів і щоденника»), значок і порядок показу.

## 8. Досягнення сина та «Оновлення»

**Досягнення сина** (слайдер на головній) редагуються в **Головна сторінка → вкладка «Досягнення сина»**.
Кожен слайд має:
- **Фото** — реальне фото.
- **Назва** (обов'язково) — наприклад, назва події.
- **Короткий опис** — один-два речення.
- **Мітка** — одне-два слова (наприклад, «Навчання»). Необов'язково.
- **Цитата на листочку** — одне речення. Необов'язково.
- **Рік або дата** — наприклад, «2024». Необов'язково.

Вигадані досягнення не додавайте: показуйте тільки справжні події. Поки слайдів немає, на сайті стоять нейтральні заготовки.

> **[Screenshot: Головна сторінка → Досягнення сина → один слайд]**

**Розділ «Оновлення» (в меню зліва).** Це записи «Що вдалося» з фото та датою. **Зараз на сайті вони не показуються** (блок прибрано з головної). Ці записи можна лишити в Studio, але на сайт вони не потраплять, поки не буде вирішено, де їх показувати. Досягнення сина краще додавати в розділі вище.

## 9. Головна сторінка

Зліва **🏠 Головна сторінка**. Це єдиний документ, його не можна створити вдруге чи видалити.

Вкладки (групи полів):
- **Головний екран:** головне фото, три рядки під назвою, короткий опис, напис на листочку.
- **Наша історія:** текст історії, фото до історії, фото на полароїді та його підпис.
- **Про сина:** показувати блок чи ні, ім'я, розповідь, «Що його радує» (до 8 пунктів), мрія (одне речення), два фото.
- **Досягнення сина:** слайди (див. розділ 8).
- **Питання:** блок «Часті питання» (питання та відповідь, українською обов'язково).
- **Інші фото:** фото біля виробів і біля збору.
- **Контакти:** посилання на Telegram, Instagram, Facebook. Порожнє поле — іконка зникне.

Вкладку **«Добрі слова»** і поле **«Ваша цитата»** не заповнюйте: вони приховані і на сайті не показуються.

---

## 10. Підтримка (збір і Monobank)

Зліва **💰 Підтримка**. Це єдиний документ, його не можна створити вдруге чи видалити.

- **Зібрано, грн** — поточна сума.
- **Мета, грн** — ціль збору.
- **Дата оновлення** — за замовчуванням сьогодні. Змініть, коли оновлюєте суму.
- **Посилання на банку Monobank** — обов'язкове, має починатися з `https://`.

Після змін натисніть **Опублікувати**. Сума оновиться на сайті.

---

## 11. Прозорість: звіти і документи

Зліва **Прозорість** → **+ Створити**.

- **Назва** (обов'язково).
- **Тип** — *Звіт про витрати* або *Медичний документ*.
- **Файл (PDF)** або **фото документа** — що-небудь одне.
- **Дата** (обов'язково).

**⚠️ Перед завантаженням приховайте особисті дані:** дату народження, адресу, номери документів і медкарти. Звичайний чорний прямокутник у PDF-редакторі часто **не** приховує текст. Використовуйте функцію **Redact** або завантажуйте вже закритий скан чи фото.

Файли на сайті не індексуються пошуковиками, а їхня назва не показується.

---

## 12. Як опублікувати зміни

1. Внесіть зміни.
2. Внизу документа натисніть **Опублікувати** (Publish).
3. Зачекайте 1–5 хвилин. Оновіть сторінку сайту, щоб перевірити.

Поки ви не натиснули **Опублікувати**, зміни бачите тільки ви в Studio. Відвідувачі їх не бачать. Якщо ви хочете відмінити незбережені правки, натисніть **Discard changes** (Відмінити зміни).

> **[Screenshot: кнопка Опублікувати внизу документа]**

## 13. Як сховати або видалити безпечно

Найбезпечніше — **сховати**, а не видаляти.

| Що потрібно | Що зробити |
|---|---|
| Тимчасово прибрати картину | Малюнки → вимкнути «Показувати на сайті» → Опублікувати |
| Прибрати кнопку «Мене цікавить» | Малюнки → вимкнути «Показувати кнопку…» → Опублікувати |
| Продано виріб | Вироби → Статус «Продано» → Опублікувати |
| Видалити виріб або запис | Відкрийте документ → меню **⋯** → **Delete** → підтвердіть |

**Увага:**
- Видалений документ відновити неможливо. Перед видаленням переконайтеся, що він більше не потрібен.
- У **Щоденнику** немає кнопки «сховати». Якщо запис не має бути на сайті, його доведеться видалити.
- Якщо видалити **Виріб**, сторінка з його адресою зникне і посилання, які на неї ведуть, перестануть працювати.

## 14. Обов'язкові і необов'язкові поля

| Розділ | Обов'язкові | Необов'язкові |
|---|---|---|
| **Виріб** | Фото (мінімум 1, максимум 5), Назва (укр.), Адреса, Статус | Опис, Ціна, англійські переклади |
| **Малюнок** | Фото, Назва (укр.) | Техніка, Рік, Теми, Показувати на сайті (за замовчуванням увімкнено) |
| **Запис щоденника** | Назва (укр.), Категорія, Текст (укр.), Дата, Адреса | Фото, Теми, Короткий опис |
| **Тема (тег)** | Назва, Тип, Адреса | Значок, Порядок |
| **Досягнення сина** | Назва (укр.) | Фото, Опис, Мітка, Цитата, Рік |
| **Головна** | — (усе необов'язкове, порожнє поле замінюється текстом за замовчуванням) | Усе |
| **Підтримка** | Зібрано, Мета, Дата, Посилання Monobank (https) | — |
| **Оновлення** | Назва (укр.), Дата | Фото |
| **Документ (Прозорість)** | Назва (укр.), Тип, Дата | Файл PDF або фото |

**Загальне правило:** якщо пишете українською і поле обов'язкове, сайт не дасть опублікувати без нього і покаже червону підказку.

## 15. Коротка пам'ятка

- Завжди натискайте **Опублікувати**, інакше зміни не з'являться.
- Фото: JPG або PNG, найдовша сторона від 1200 px (рекомендація), Hotspot на обличчя.
- Вигадані факти, ціни та досягнення не додавайте.
- Продане — змінюйте статус, а не видаляйте.
- Документи — спершу приховайте особисті дані.
- Сумніваєтеся — нічого не видаляйте, а сховайте або напишіть розробнику.
